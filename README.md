# 🕵️ Investigation Game

משחק חקירה פשוט בקונסולה (C#), שבו אתה בתור חוקר מנסה לחשוף את החולשות של סוכן איראני באמצעות הפעלת סנסורים.

---

## 🎯 מטרת המשחק

לגלות את שני סוגי הסנסורים שמהווים חולשה של הסוכן.  
כל תור אתה מפעיל סנסור ובודק אם הוא פוגע.  
כאשר כל החולשות מתגלות – הסוכן נלכד.

---

## 🧱 מבנה הפרויקט

```
InvestigationGame/
├── Program.cs         // הלוגיקה הראשית של המשחק
├── IranianAgent.cs    // מייצג את הסוכן והחולשות שלו
├── SensorMenu.cs      // תפריט לבחירת סנסורים
```

---

## 🎮 איך משחקים

1. בכל תור יוצג תפריט עם סנסורים.
2. תבחר סנסור שתרצה להפעיל על הסוכן.
3. המשחק יאמר לך האם פגעת באחת מהחולשות.
4. אם שתי החולשות נחשפו – ניצחת.

---

## ✅ גרסת בסיס (MVP)

- סוכן מסוג **זוטר** בלבד  
- שתי חולשות מסוגי סנסור פשוטים: `Base`, `thermal`  
- אין התקפת נגד  
- תפריט פשוט לבחירת סנסור  
- לוגיקה בסיסית של בדיקת פגיעות
